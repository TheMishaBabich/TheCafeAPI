**Issue 1: Install Docker**
Description: To run TheCafeAPI locally, Docker is required. If Docker is not already installed, please follow these steps.

**Steps to Install Docker:**

1.Go to Docker's official website https://www.docker.com/ and download Docker Desktop for your operating system.
2.Install Docker Desktop by following the provided instructions.
3.Start Docker Desktop to ensure it is running properly.

Docker is installed and running.

**Issue 2: Clone the Repository**
Description: Clone the TheCafeAPI repository from GitHub to your local machine.

Steps to Clone:

1.Open a terminal or command prompt.

2.Run the following command to clone the repository:

`gh repo clone TheMishaBabich/TheCafeAPI`

**Issue 3: Build and Run with Docker Compose**
Description: Use Docker Compose to build and start TheCafeAPI application.

Steps to Run:

1.Navigate to the cloned TheCafeAPI directory in your terminal.

2.Run the following command to build and start the containers:

`docker-compose up --build`

Wait for the process to complete; this may take a few minutes.

Acceptance Criteria:

The application builds and runs without errors.
The application is accessible at http://localhost:docs
**Issue 4: Access API Documentation**
Description: After successfully starting the application, check the API documentation to confirm that everything is set up correctly.

Steps to Access Documentation:

Open a web browser.

`Go to http://localhost/docs`

Acceptance Criteria:

**API documentation page loads successfully.
You can interact with the API docs on the page.
Let me know if you'd like further refinements or additional issues!**
